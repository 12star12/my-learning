# 量化

量化投资方向的学习资料与研究笔记。

## 经典文献拆解

| 文件 | 内容 |
| --- | --- |
| [**Alpha101-目录.md**](./Alpha101-目录.md) | 94 页报告的完整目录（14 章 + 3 附录），带页码，可快速定位某一节 |
| `Alpha101从零开始的深度拆解与通俗化研究报告.pdf` | 对 101 个公式化 Alpha 的逐条核对与九环节拆解。含 20 个基础概念、八类思想地图、生活化迁移与独立研究指南 |

参考原文：Zura Kakushadze, *101 Formulaic Alphas*,
arXiv:[1601.00991](https://arxiv.org/abs/1601.00991)，Wilmott Magazine 2016(84): 72–80

### 读法建议

1. 先读第三、六章（基础概念 + 数学思想），跳过第四章的公式细节
2. 带一个具体问题回第四章查对应分组，别逐条通读
3. 第五、八章动手：把八类思想翻成自己的表达式，九步流程走一遍
4. 第九章最后读——它会告诉你前面的数字为什么不能当真
